GUÍA RÁPIDA

Ayuda y compatibilidad

Lo esencial para empezar y entender los límites del navegador.

01

Importa tu lista

Usa un archivo .m3u/.m3u8 o pega una URL. Las listas remotas dependen de que el servidor permita solicitudes desde tu navegador (CORS).

02

¿Un canal no reproduce?

El proveedor puede estar desconectado, requerir autenticación o usar un formato no compatible con el navegador. TesitoTV no puede saltarse esas restricciones.

03

Compartir en GitHub

Puedes exportar una lista y subirla a tu repositorio. Publica solo contenido que tengas derecho a compartir; una lista pública puede ser copiada por cualquiera.

04

Privacidad primero

Los datos de la biblioteca se guardan en este navegador. No publiques enlaces que contengan contraseñas, tokens o información privada.

05

Formatos de vídeo

HLS suele funcionar con HLS.js o reproducción nativa. MP4/WebM dependen de los códecs del navegador. No todos los flujos MPEG-TS ni todos los audios MP2 son compatibles.

06

Atajos del reproductor

Usa ↑ y ↓ para cambiar de canal cuando el reproductor está activo; Espacio para pausar; F para pantalla completa; M para alternar audio.

07

Copias de seguridad

Exporta toda tu biblioteca como archivo JSON para conservar listas, categorías, logos, favoritos y preferencias. Después puedes restaurarla en otro navegador.

08

Diagnóstico de canales

Busca URLs de señal repetidas, nombres de canales repetidos, canales sin URL y direcciones sospechosas. También puedes comparar dos listas para ver qué canales cambiaron.
